# 05 · 开发路线图

> 以「尽快跑通 MVP」为第一原则排期。M1 是核心冲刺，M2 起按用户反馈动态调整。

## 里程碑总览

| 里程碑 | 版本 | 主题 | 状态 |
|---|---|---|---|
| M0 | — | 项目初始化（脚手架规划 + 文档） | ✅ 已完成 |
| M1 | v0.1.0 | MVP：数据层 + 树形视图 + 状态传播 + 平铺视图 | ✅ 已完成（待打包冒烟） |

## M1 · v0.1.0（MVP）

**目标**：一个能日常自用的最小可用版本——「能用它管理自己手头的任务树」。

### 任务拆解（建议顺序）

1. **脚手架**：`create-tauri-app`（React + TS + Vite 模板）跑通 `pnpm tauri dev`，接入 Tailwind、Zustand。
2. **数据层（Rust）**：
   - [ ] `nodes` 表 + 迁移框架（`schema_version`）
   - [ ] Node 结构体 + CRUD command（create / update / delete / get_tree / list_leaves）
   - [ ] **propagate.rs 传播引擎**（规则表 C1/M1/M2/M3/D1 + 向上传播 + 事务）
   - [ ] 单元测试：规则全覆盖 + Corner Cases CC1–CC8 + 深树性能用例
3. **前端骨架**：IPC 封装（`src/ipc/`）、Zustand store（数据快照 + 选中 / 视图模式）、布局壳（顶栏 + 状态栏）。
4. **树形视图**：
   - [ ] d3-hierarchy 布局 + react-flow 渲染（多根水平树）
   - [ ] 节点组件（checkbox / 文字 / 折叠钮 / done 样式）
   - [ ] 画布缩放平移 + 适应视图
   - [ ] 键盘操作流（N / Tab / Enter / F2 / Delete / Space / ↑↓）
5. **平铺视图**：叶子分组列表 + 面包屑 + 点击定位树形。
6. **收尾**：状态栏统计、空态引导、启动备份、`tauri build` 出包冒烟（Windows + macOS）。

### 验收标准（Definition of Done）

- [ ] 全部 P0 功能可用，核心键盘流（N→输入→Tab→输入→Space）无断点；
- [ ] 状态传播经手工 + 自动化测试双重验证（重点：CC1 在 done 父下建子、CC2 全子完成父自动完成、CC3 取消父级联重开）；
- [ ] 5000 节点（深 15 层）树：折叠后滚动缩放不卡顿（≥ 45fps 主观流畅）；
- [ ] Windows 11 + macOS 14 安装包可安装、可启动、数据落盘正确；
- [ ] 无「保存」按钮，关闭重开数据无丢失。

## M2 · v0.2.0

- **拖拽移动**：拖到目标节点上方（内边缘 = 作为子节点，下边缘 = 作为兄弟），含防环校验（`CyclicMove`）；
- **撤销 / 重做**：Rust 侧命令模式（反向操作栈），前端 `Cmd/Ctrl+Z`、`Cmd/Ctrl+Shift+Z`，上限 100 步；
- **全文搜索**：`Ctrl+F`，内容匹配高亮 + 结果间跳转定位；
- **节点备注**：选中节点右侧滑出详情面板（note 编辑，纯文本）；
- **JSON 导入导出**（格式按 `02-data-model.md` §5，导入后强制传播校正）;
- **同级排序**：Alt+↑/↓ 上下移；折叠/展开全部；
- **删除体验升级**：静默删除 + toast 撤销（替代确认气泡）。

## M3 · v0.3.0

- 明暗主题手动切换 + 跟随系统（若 v0.1 未完成手动切换部分）；
- **多文档**：左侧边栏管理多棵树（每个文档独立 db 文件，切换即换数据源）；
- **回收站**：删除改软删除（`deleted_at`），回收站内恢复 / 彻底删除；
- **统计面板**：按根任务线统计完成率 / 最近 7 天完成数；
- 备份保留 3 份 + 手动「立即备份」入口。

## M4 · v1.0.0

- Windows 代码签名（EV 证书视预算）+ macOS 签名公证（必须，否则 Gatekeeper 拦截）；
- 自动更新（tauri-plugin-updater）；
- 官网 / 落地页 + 分发渠道（官网直链为主，视情况上架 Microsoft Store）；
- 性能终测：2 万节点场景验证；
- （调研）iCloud / WebDAV 多设备同步方案。

## 工程节奏约定

- 分支：`main` 保持可构建；功能走 `feat/xxx` 短生命周期分支，PR 自查后合入；
- 提交：Conventional Commits（见 `AGENTS.md`）；
- 每个 milestone 结束：更新 `CHANGELOG.md` + 打 tag + 归档验收清单。
