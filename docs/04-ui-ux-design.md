# 04 · UI / UX 设计

> 设计原则先行，再谈布局、视觉与交互细节。目标：一个「打开就在、用完即走」的效率工具。

## 1. 设计原则

1. **内容即界面**：无干扰，画布（列表）占满窗口；工具栏极薄、可收起。
2. **键盘优先**：目标用户（开发者 / 重度效率用户）期望双手不离键盘完成 90% 操作（脑图工具的通行惯例）。
3. **状态可见性**：任何节点的 pending / done 一眼可辨；「哪条任务线还堵着」是用户打开本产品的第一诉求——视觉上要能立刻回答。
4. **克制动效**：布局过渡 ≤ 200ms，只用于结构变化的因果传达（新节点从父节点位置展开），不做装饰性动画。
5. **深色优先，明暗随系统**：v0.1 实现两套主题变量（Tailwind `dark:` 类），默认跟随系统。

## 2. 窗口布局

```
┌──────────────────────────────────────────────┐
│ ◆ tree-todo        [树形|平铺]  [+ 新任务]  ⌕  │ ← 顶栏（可隐藏，Ctrl+Shift+B）
├──────────────────────────────────────────────┤
│                                              │
│              画布（树形视图）                    │
│          或 平铺列表（平铺视图）                  │
│                                              │
│                                              │
├──────────────────────────────────────────────┤
│ 12 待处理 · 34 已完成 · 叶子完成率 74%          │ ← 状态栏：统计 + 缩放控制
│                              [−][100%][＋][⤢]│
└──────────────────────────────────────────────┘
```

- v0.1 单一窗口；侧边栏（多文档树）是 v0.3 的扩展位，布局上预留左侧空间但不实现。节点详情面板已移除，备注改为节点内联方案（待重设计）。
- v0.4 起树形视图由 Mind Elixir 渲染，节点 checkbox 与 done 视觉叠加在其原生节点卡片上；折叠角标保持 Mind Elixir 原生样式。
- v0.5 侧边栏升级为**层级目录树**：同一时刻只有一个选中项（选中目录决定「+」新建落点，选中文档则打开它）、箭头展开折叠、右键管理；同级目录与文档的图标垂直对齐；宽度可拖拽（180–420px），松手即记忆，下次启动保持。
- v0.6 侧边栏：产品名「Tree Todo」+ 右侧版本号；目录 / 文档支持拖拽排序与移入目录；点击空白清除选中，空白右键可新建；新建后输入框自动聚焦并留空；新建项置于同级最上方。
- 2.0 侧边栏拖拽改为**指针拖拽**（不依赖 HTML5 drag-and-drop）：跟手标签 + 插入线 / 目录高亮三态、拖到空白回到根层级末尾、悬停折叠目录 500ms 自动展开、Esc 取消；详见 `docs/03-feature-design.md` 文档与目录章节。
- 2.0 左上角版本号可点击（accent 蓝色下划线 + hover 加深）：点击检查更新，无更新 toast「已是最新版本」，有更新弹出更新弹窗。系统菜单同步提供「检查更新…」（macOS 应用名菜单 / Windows Help 菜单首项）。
- 全局导出 / 导入放在**系统菜单栏的 File 菜单**（macOS 屏幕顶部、Windows 窗口菜单），顶栏不再有「文件」按钮；顶栏右侧为「更多 ▾（主题 / 导出）/ 快捷键」，「快捷键」替代原「新建任务」按钮，悬停展开半透明教程面板。
- 树形视图工具区（搜索 / 折叠 / 展开之后）为「隐藏已完成节点」小眼睛开关（文档级、记忆），激活时用 accent 高亮。
- 回收站同时展示文档与目录条目，目录条目显示「N 个文档 · M 个子目录」，恢复即整体还原。
- 平铺视图为左右双栏：左「待处理」、右「已完成」，各自独立滚动。
- 树形视图视口（平移 / 缩放）按文档独立记忆：新建文档 100% + 根节点居中，切换文档或切换视图不会互相污染。
- 窗口最小尺寸 800×600，默认 1280×800，记住窗口位置与尺寸。

## 3. 视觉设计

### 3.1 主题与色彩（Tailwind CSS 变量，两套同名 token）

| Token | 暗色（默认参考） | 亮色（参考） | 用途 |
|---|---|---|---|
| `bg-base` | `#16181d` | `#f7f8fa` | 窗口 / 画布底 |
| `bg-node` | `#1f232b` | `#ffffff` | 节点卡片 |
| `text-primary` | `#e7eaf0` | `#1a1d23` | 正文 |
| `text-muted` | `#8b93a1` | `#6b7280` | 面包屑 / 次要信息 |
| `accent` | `#4f8cff` | `#2f6fed` | 选中描边 / 焦点 / 主按钮 |
| `success` | `#3ecf8e` | `#16a34a` | done 状态 |
| `warning` | `#f5a623` | `#d97706` | 折叠角标 / 提示 |

- 遵循中国用户视觉习惯，色彩仅用于状态语义（成功 / 提示 / 选中），不做花哨配色。
- 字体：系统字体栈（`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`），节点文字 14px / 行高 22px，面包屑 12px。

### 3.2 节点视觉规格

```
普通节点                 选中节点
┌──────────────┐        ╔══════════════╗
│ ○ 买域名      │        ║ ○ 买域名      ║   ← accent 描边 1.5px
└──────────────┘        ╚══════════════╝

已完成节点                有子节点（未折叠）
┌──────────────┐        ┌───────────────●─┐
│ ✓ 买域名 ~~~~ │        │ ○ 上线准备    [−]│   ← 折叠按钮
└──────────────┘        └─────────────────┘
                              opacity ↓ 40%

已完成分支：节点置灰 + 文字划线，其所有连线整条变灰。
```

- checkbox 直径 16px，命中区域扩至 24px（触控板友好）。
- checkbox 固定在节点最左侧、相对整个节点垂直居中；文本在右侧文本区内折行，任何长度都不会把 checkbox 挤到单独一行。
- done 文字 `line-through` + `opacity 0.5`；分组上「视觉降噪」让完成的支线自动退后。
- 节点尺寸（对齐钉钉脑图的紧凑密度）：左右内边距 8px、上下 4px、边框 1px、圆角 6px；
  单行高度 32px；宽度随内容自适应，最小 80px；文本区最大宽度 320px，超出后折行，
  不截断、不省略，节点高度随行数增长（行数 × 22px + 上下留白）。
- 编辑态使用 Mind Elixir 的内联输入层，支持多行文本；提交后节点宽度/高度随内容重新布局。
- 执行状态徽标（docs/06 §9.4）：节点卡片右下角一行小字（执行中 / 待验收 / 失败 + 耗时），
  **12px / 行高 16px**，卡片底部为它预留 20px，不参与文本折行；平铺视图的执行状态 chip 同为 12px。

### 3.3 连线

- 三次贝塞尔曲线，1.5px，颜色 `accent` 45% 透明（与钉钉脑图一致的蓝色枝干）；
- done 支线的连线降低透明度至 12%，形成「已走完的路自动暗下去」的阅读引导。

## 4. 关键交互流程

### 4.1 空态引导

首次启动 / 空树时，画布中央显示：

> **从这里开始你的第一条任务线**
> 按 `N` 新建任务，`Tab` 拆解子任务，点击 checkbox 或按 `S` 完成它

### 4.2 新建节点的心流

1. `N` → 在根任务下创建第一个任务，**直接进入编辑态**，光标就位；
2. 输入内容 → `Tab` 提交 → 再次 `Tab` 创建子节点并继续编辑；
3. 拆完一条线 → `Enter` 提交 → 再次 `Enter` 回到同级继续 → `↑` 回到父节点。

编辑即入口：**创建的节点永远直接进入编辑态**，绝不让用户「先创建再双击编辑」。

### 4.3 完成与回退的可感知性

- 完成 / 取消（尤其带级联时）是本项目最「自动」的行为，必须让用户看懂：
  - 完成父节点 → 整棵子树变灰（含动画渐隐），用户自然理解「连子任务一起完成了」；
  - 在 done 节点下新增子节点 → 父节点从灰恢复彩色 + 短暂高亮脉冲一次，用户自然理解「它又活了」。
- 所有级联操作在状态栏出现 toast：「已完成 12 个子任务 · 撤销」。

### 4.4 危险操作

- 删除有子孙的节点 → 静默物理删除 + toast 可撤销（Rust 历史快照恢复）；
- 删除文档 → 移入文档回收站，可从回收站恢复或彻底删除。

### 4.5 检查更新（v2.0.0）

- **入口**：左上角版本号（`text-accent` + 下划线，检查中显示 10px 旋转指示）、系统菜单「检查更新…」；启动 3s 后自动检查一次。
- **无更新**：手动态 toast「已是最新版本」（5s）；自动态静默。
- **有更新**：居中弹窗（460px，`bg-elevated` + `border-border` + `shadow-2xl`）：
  - 头部「发现新版本」+ 关闭；
  - 版本行 `v当前 → v最新`（最新版 accent 加粗，右侧可选发布日期）；
  - 版本介绍区（`bg-base`、最大 220px 可滚动、纯文本 `whitespace-pre-wrap`）；
  - 底部「稍后」+ 主按钮「立即更新」（macOS 为「前往下载」并打开 Releases 页面）。
- **下载中**：进度条 + `42% · 3.2 / 7.6 MB`，主按钮禁用；关闭弹窗不中断下载，重开可见进度。
- **安装中**：显示「正在安装，应用即将重启…」，禁止关闭；Windows 安装时应用自动退出。
- **失败**：弹窗内红字给出可读原因 + 「重试」；自动检查失败不打扰用户。
- 有任务正在执行时，弹窗提示「有 N 个任务正在执行，更新会重启应用；执行记录会保留」。

## 5. 快捷键总表（v0.1）

| 键 | 场景 | 动作 |
|---|---|---|
| `N` | 树形视图 | 在根任务下新建顶层任务 |
| `Tab` | 选中节点 | 新建子节点；编辑态中=提交当前编辑 |
| `Enter` | 选中节点 | 新建兄弟节点；编辑态中=提交当前编辑；根任务上=新建子任务 |
| `S` | 选中节点 | 切换完成 / 待处理（也可直接点击 checkbox） |
| `Space` | 画布 | 按住 Space + 拖拽平移画布（Mind Elixir 原生） |
| `F2` / 双击 | 选中节点 | 编辑 |
| `Esc` | 编辑态 | 取消编辑；搜索层=关闭搜索 |
| `Delete` / `Backspace` | 选中节点 | 删除（根任务不可删除） |
| `↑` / `↓` | 全局 | 焦点移动（Mind Elixir 原生导航序） |
| `←` / `→` | 树形视图 | Mind Elixir 原生方向导航 |
| `Ctrl+1` / `Ctrl+2` | 全局 | 切换树形 / 平铺视图 |
| `Ctrl+.` / `Ctrl+,` | 选中节点 | 折叠 / 展开 |
| `Shift+1` | 树形视图 | 适应整树视图 |
| `Ctrl+Shift+C` / `Ctrl+Shift+R` | 树形视图选区 | 复制 Prompt（纯文本 / 带回执）；多选时合并为一个 Prompt |
| `Ctrl/⌘+点击`、`Shift+点击`、`Ctrl/⌘+拖框` | 树形视图 | 多选节点（Mind Elixir 原生）；右键落在选区内时，菜单作用于整个选区 |
| 触控板双指捏合 / 缩放控件 | 树形视图 | 缩放 |
| 按住 Space + 拖拽 / 拖拽空白 / 双指拖动 | 树形视图 | 平移画布 |

> macOS 相应替换为 `Cmd`；`Ctrl` 一律映射 `⌘`，行为一致。

## 6. 可访问性基线

- 所有交互元素可 Tab 聚焦（编辑态外），焦点环可见；
- 颜色对比度满足 WCAG AA（正文 ≥ 4.5:1）；
- 状态不只靠颜色表达：done 同时有 ✓ 图标与划线。
