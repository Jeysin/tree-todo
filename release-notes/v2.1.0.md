Tree Todo 2.1.0 · 全局总览、Linux 安装包与中英双语

- 新增全局总览：侧栏常驻「总览」入口（⌘/Ctrl+4），GitHub 风格 53×7 年度日历热力图，反映每天完成的叶子任务数
- 总览配 4 个 KPI（范围内完成 / 活跃天数 / 当前连续 / 最长连续），点格子可下钻到当天完成的任务
- 统计范围改用目录树式文档选择器，可搜索、可展开折叠，替代原先含糊的「当前文档」下拉
- 关窗口前停在哪一页，下次打开就回到那一页（只记视图，不记滚动位置与选中日期）
- 新增 Linux 安装包：.deb / .rpm / AppImage，兼容 Ubuntu 22.04+ 与 Debian 12+
- 界面支持中英双语：设置 → 语言，默认按系统语言与时区判断，可随时切换
- 设置页可关闭本地 MCP 服务：关闭立即停止监听并释放端口，开启时沿用原端口，已配好的 Agent 不受影响
- 节点右键菜单新增「删除」，多选可整批删除，根任务受保护
- 修复：MCP 关闭再打开会漂移端口；总览与文档同时显示为选中；重启后主题回到「跟随系统」；年视图缺「1月」标签
- Windows 可直接在应用内更新；macOS 与 Linux 会打开下载页，需手动安装
- Linux 安装：sudo apt install ./<文件名>.deb 或 sudo dnf install ./<文件名>.rpm；AppImage 需 chmod +x 后运行
- macOS 首次打开若被系统拦截，请右键「打开」，或到「系统设置 → 隐私与安全性」中允许
